Evidence-first retrieval

Scope
This is an original educational workflow, not a published method or an empirical result. It illustrates how a retrieval system can keep answer generation connected to source passages. There are no measured accuracy, latency, or performance claims.

Method
A user question is the input. The question is sent to two parallel retrieval branches: lexical retrieval and semantic retrieval. Both branches search the same document collection. Lexical retrieval matches query terms to passages. Semantic retrieval compares a query embedding with passage embeddings. The two branches send their candidate passages to a shared reranker. The reranker orders the combined candidates and removes duplicates. It passes the selected passages to an evidence pack. The evidence pack stores passage text together with a document identifier and a section reference. A grounded answer generator receives both the original user question and the evidence pack. The answer generator produces an answer with citations pointing back to the evidence pack. A reviewer can inspect the cited passages. When the evidence is insufficient, the answer explicitly reports uncertainty instead of inventing support.
