# Brand Assets

The OpenAI edition uses a cobalt folded-ribbon symbol. The open center and broad
silhouette keep the mark readable without inserting charts or labels into the icon.

| Asset | Use |
| --- | --- |
| [`logo.png`](../logo.png) | Canonical transparent PNG, used in both README versions |
| [`frontend/public/logo.png`](../frontend/public/logo.png) | 256-pixel app icon |
| [`frontend/public/favicon.png`](../frontend/public/favicon.png) | 64-pixel browser favicon |

The browser assets are reduced copies of the canonical PNG, with transparency
preserved. Do not add a solid background, round the silhouette with CSS, or stretch
the mark. Leave its built-in clear space intact.
